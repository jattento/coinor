# Conan Code 0.4.0

Conan Code now includes a permanent IDE workspace beside every Grok
conversation.

## Highlights

- Added a fixed `IDE` tab immediately after `main`.
- Added an embedded Fresh editor running `fresh .` in the larger left pane.
- Added Lazygit in the right pane with a fixed responsive 60/40 split.
- Launches both IDE tools eagerly when a conversation runtime activates.
- Resolves the IDE working directory to the conversation's Git root, including
  worktrees, and shows the existing inline error when that directory is gone.
- Added `Command-2` for IDE selection while preserving shell tabs from the
  third position onward.
- Keeps `main` and `IDE` fixed: they cannot be closed, renamed, or reordered.
- Restores focus to the last-used IDE pane and recreates IDE processes after
  relaunch without treating them as persisted shell-tab metadata.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Coinor application
  support paths.
- Metadata remains on schema 3; the IDE tab is derived rather than persisted as
  shell metadata.
- Existing projects, conversations, shell-tab labels, order, selection, and
  numbering remain compatible.
- Fresh and Lazygit must be available on the Finder-launched application PATH
  as `fresh` and `lazygit`.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- Debug and Release Apple Silicon builds completed.
- 195 unit and integration tests plus 3 XCUITest passed with no failures or
  skips.
- Real-app QA covered fixed tab ordering, `Command-2`, `Command-W`, shell
  creation and close fallback, project Git roots, missing worktrees, wide and
  compact 60/40 layouts, hidden-conversation continuity, and process resource
  use.
- The release bundle, repository boundaries, Ghostty artifact, source delta,
  archive, and release notes passed their verification and security gates.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
