# Conan Code 0.6.2

Mirrors ego lite Browser Spaces as live read-only tabs, and fixes the
letterboxing that showed a black band around the mirrored page.

## Live preview of ego lite Task Spaces

Conan Code now watches the terminal-command activity every `ego-browser`
invocation already produces and opens a Browser Mirror tab in the current
conversation that mirrors the Task Space an agent is driving. The tab
refreshes while visible, backs off when backgrounded, closes itself when the
Task Space activity finishes, and reports clearly when the `ego-browser` CLI
is not installed instead of blocking anything.

- Detection parses the same ACP `tool_call` stream already consumed for
  terminal-control, so the mirror appears with no agent-facing protocol or
  cooperation: `useOrCreateTaskSpace`/`takeOverTaskSpace` opens a tab,
  `completeTaskSpace`/`closeTaskSpace` closes it.
- A per-tab poller shells out to the installed `ego-browser` CLI and captures
  one screenshot per tick over the Chrome DevTools Protocol, at a cadence
  adapted to whether the tab is visible. A warm poll is roughly 100-160ms.
- An "Open in ego lite" action activates or foregrounds the Task Space in the
  real ego lite window.
- A bundled `conan-code-browser` skill steers agents toward `ego-browser`
  while inside Conan Code and explains the preview is automatic; it never
  modifies the third-party skill files.
- The mirrored image now fills the tab and crops instead of letterboxing, so
  the mismatch between ego lite's window aspect ratio and the tab's no longer
  reads as a broken black band; the crop trims the bottom of the page, never
  its header.
- The mirror is local-only, exactly like managed terminal tabs: remote-host
  conversations do not get one.

## Validation

- Debug build, Release build, and bundle verification on the pinned toolchain
  (Xcode 26.6, macOS SDK 26.5, Swift 6.3.3).
- Full test suite: unit tests covering the passive detector, poller cadence,
  screenshot-client parsing, the runtime tab lifecycle (reuse, close, orphan,
  again-same-owner reopen), and the gated live E2E test that drives the real
  `ego-browser` CLI; no regressions.
- Security gate over Git history, the working tree, and the application
  bundle.
