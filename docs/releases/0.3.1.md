# Conan Code 0.3.1

Coinor is now presented as Conan Code, a playful nod to Claude Code, while
retaining its existing repository, bundle identifier, executable, and local
data paths for compatibility.

## Highlights

- Replaced the generic connection spinner with a Conan Code startup screen
  featuring a friendly ASCII portrait of Conan, live connection diagnostics,
  elapsed time, and a retry action when startup fails.
- Renamed all user-visible Coinor branding to Conan Code without renaming the
  repository or changing internal compatibility identifiers.
- Made project and conversation rows reliably clickable across their full
  width while keeping pin, archive, and project actions independently usable.
- Scoped sidebar hover state to each row so moving across the conversation
  list no longer causes unrelated controls to churn.
- Deferred terminal resize work for hidden tabs, allowing sidebar resizing to
  update only the visible Ghostty surface instead of every retained terminal.
- Removed the background extension effect that produced a reflected duplicate
  of the tab strip above the real tabs.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Coinor application
  support paths.
- The repository remains named `coinor`.
- Metadata remains on schema 3, so existing projects, conversations, and
  terminal-tab state continue to load without migration.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- Debug and Release Apple Silicon builds were completed.
- 191 unit tests and 3 XCUITest passed with no failures or skips.
- Unit coverage includes full-row sidebar activation, control isolation,
  startup presentation, and visible-only Ghostty resize policy.
- Real-app QA covered the Conan startup screen, tab-strip rendering, sidebar
  interaction, and visible-versus-hidden terminal resizing.
- The release bundle, repository boundaries, Ghostty artifact, source delta,
  archive, and release notes passed their verification and security gates.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
