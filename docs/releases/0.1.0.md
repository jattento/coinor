# Coinor 0.1.0

Coinor is a native Apple Silicon macOS workspace for durable Grok
conversations. This first public release includes:

- A Codex-like project and conversation sidebar backed by Grok's persisted
  sessions.
- Flat grouping of main-checkout and worktree conversations under one project.
- Local project display names and selectable SF Symbol icons.
- Pinning, archiving, exact session resume, and named worktree creation.
- Interactive Ghostty terminals for the root agent and every active native
  subagent, with the root retaining the left 50 percent.
- Native ACP subagent lifecycle handling with no global Grok hooks or hook
  status noise.
- Complete handling for arrows, navigation, editing, function, and other
  special terminal keys.
- Adaptive sidebar controls, lighter row typography, and the native macOS 26
  Liquid Glass sidebar with a standard system fallback on earlier releases.
