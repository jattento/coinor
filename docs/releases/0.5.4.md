# Conan Code 0.5.4

The startup loading screen's ASCII mascot artwork was replaced with new
artwork supplied by the owner.

## Highlights

- `ConanASCIIView` in `ConversationContentView.swift` now renders a single
  ASCII-art block instead of the previous three-part colored dog drawing
  (face, tongue, harness). The "CONAN" caption underneath is unchanged.
- The accessibility label no longer describes "a happy black dog with
  floppy ears," since that text no longer matches the artwork; it now reads
  "Conan, the Coinor mascot."
- No application logic, layout contract, or other view changed. This is a
  presentation-only change to the startup/failed-startup screen.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Application Support
  paths.
- Existing metadata remains compatible.
- The bundled Ghostty dependency remains pinned to v1.3.1.
