# Conan Code 0.5.1

Conan Code now keeps trackpad and Magic Mouse scrolling controlled inside every
embedded terminal surface, and handles service-like commands through visible
managed tabs automatically.

## Highlights

- Preserved AppKit's high-precision scroll metadata when forwarding trackpad
  and Magic Mouse events to Ghostty.
- Preserved momentum phases for natural inertial scrolling.
- Kept precise deltas unamplified so main Grok, subagent, IDE, shell, and
  managed terminal tabs no longer interpret every small gesture as a discrete
  wheel tick.
- Left sidebar conversation scrolling unchanged.
- Made managed terminal tabs the automatic path for servers, databases,
  container stacks, watchers, streaming logs, REPLs, daemons, and services.
- Kept finite setup, build, test, and migration commands on the ordinary
  terminal path.
- Required agents to interrupt and close managed tabs before their final
  response unless the user explicitly asks to keep a specific service running.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Application Support
  paths.
- Existing metadata remains compatible.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- Focused scroll-event mapping tests cover precise and discrete devices plus
  every Ghostty momentum phase.
- Managed-terminal policy tests cover automatic selection and cleanup
  requirements.
- 207 unit and integration tests and 3 XCUITests passed with no failures or
  skips.
- Real Release QA confirmed controlled precise scrolling, unchanged native
  sidebar scrolling, and automatic managed-tab service startup and cleanup.
- Release build, bundle verification, Ghostty corruption checks, repository
  boundary checks, and security scanning passed for the published artifact.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
