# Conan Code 0.6.3

Native mouse routing in the terminal, an optimistic sidebar rename, and
automations that run live inside Conan Code's own leader connection instead of
as disconnected background processes.

## Native mouse routing

Conan Code used to rewrite mouse gestures before handing them to the embedded
terminal. While an application had mouse reporting enabled, it held the left
press back, and once the pointer moved it replayed the gesture with Shift
forced on so the terminal made its own selection. That is why dragging over
Grok's interface produced a full-width terminal selection that swallowed the
vertical rule down the side of the transcript and broke the copied text, while
the same drag under Ghostty gave Grok's own clean selection.

- Presses, releases, drags, and modifiers now reach libghostty verbatim. Conan
  Code no longer defers a press, synthesizes a modifier, or decides locally
  whether a gesture is a selection; Ghostty's core arbitrates, exactly as it
  does for Ghostty itself.
- Grok therefore owns dragging inside its own interface and produces its own
  selection, and Shift-drag still makes a terminal selection.
- Middle click and the extra mouse buttons now reach the terminal, so
  middle-click paste and back/forward buttons work.
- Force click reports pressure and opens Quick Look, and the release resets
  pressure the way Ghostty does.
- Precise trackpad scrolling carries Ghostty's 2x multiplier, so scrolling
  travels the same distance as in Ghostty.
- A click that only moves focus to an unfocused pane of an already active
  window transfers focus without also landing in the terminal.

## Optimistic sidebar rename

Renaming a conversation from the sidebar used to feel slow: the title only
updated once the rename request, a full paginated re-list of every persisted
session, a roster re-fetch, and a per-session Git resolution pass all
completed. The sidebar now shows the new title the instant the user confirms
it; a rename Grok rejects reverts the title once the failure is known.

## Live automations

An automation used to run as a `grok -p` process launchd spawned entirely on
its own, with no connection to Conan Code's control plane. If Conan Code's GUI
happened to be open at the time, the run stayed invisible to it: no live
status in the sidebar, and opening the conversation attached a second,
disconnected process to the same session.

- The launchd job's script now checks whether Conan Code's GUI is running. If
  it is, the script hands the run off to it (a `coinor://run-automation`
  URL) instead of running Grok itself.
- Conan Code executes the automation through its own persistent control-plane
  connection — the same one every pane and the Telegram bridge already
  share — so the run is resident in that connection's session roster and its
  activity is live in the sidebar immediately.
- When Conan Code's GUI is not running, the job runs `grok` headlessly by
  itself exactly as before. Either path records the run identically in the
  automation history.

## No-vision model image handling (Grok fork)

A model marked "(NV)" (no vision) used to receive an image anyway, wait a full
round trip for the provider to reject it, and only then have the image
stripped and the request retried. The fork now checks the target model's
vision support before the request goes out and, for a no-vision model,
replaces each image with a text note naming where it is, so the agent can act
on it directly — read or describe it with a tool, delegate to a vision-capable
model, or ask the user — instead of losing the round trip and the context.

## Validation

- Debug build, Release build, and bundle verification on the pinned toolchain
  (Xcode 26.6, macOS SDK 26.5, Swift 6.3.3).
- Full Coinor test suite, including new cases for the libghostty button-number
  mapping, the focus-transfer rule, the pointer-exit sentinel, the doubled
  precise scroll deltas, the optimistic-rename rollback, and the live
  automation hand-off (both branches run for real against a stub `grok` and
  stand-in `pgrep`/`open`).
- Grok fork: `overlay-core`, `overlay-conversation`, and
  `xai-grok-sampling-types` unit tests, plus `overlay/scripts/overlay-diff.sh`
  (touchpoint and delta-budget gates).
- Byte-level verification against a terminal application with SGR mouse
  tracking enabled, plus manual verification against a live Grok pane.
- Security gate over Git history, the working tree, and the application
  bundle, for both repositories.

## Artifact

`Coinor-0.6.3-arm64.zip` is an ad-hoc signed, non-notarized personal build for
Apple Silicon running macOS 13 or newer.
