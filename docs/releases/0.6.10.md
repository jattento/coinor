# Conan Code 0.6.10

Polishes the Activity Stack's fluidity after real usage surfaced three focus
bugs and a missing interaction.

## Fixes

- **Auto-focus on open.** `close()` used to leave `focusedID` pointing at
  whatever was last shown. Reopening the panel could therefore resume a
  stale selection instead of the true current head of the queue, requiring
  a manual click. Closing the panel now always drops focus, so every
  `present()` lands on the queue's first item deterministically.
- **Stuck "send to end".** `⌘S` ("send to end") only meant to hold for the
  current instance of attention, per its own intent, but the pushed
  position was never cleared once an item actually left the queue. A
  conversation ever pushed to the back stayed pinned there forever, even
  for a brand-new, unrelated question or failure much later — which could
  look like "the wrong item is marked as next." Pushed order is now dropped
  the moment an item leaves the queue.
- **Slow to notice the queue changed.** The presented-panel backstop tick
  dropped from 20s to 5s, and `reconcileFocus` now runs on every recompute
  (including that tick), so a queue that changed without a timely
  `AppCoordinator` notification self-corrects within a few seconds instead
  of sitting stale until the next unrelated update.

## New interaction

- The sidebar's "N agent(s) working" rows are now clickable. Tapping one
  focuses that conversation in the Activity Stack's own pane (the same
  "watching" state a resolved queue item falls back to), so the user can
  check in on a working agent's live terminal without leaving the panel.
  Watching a working agent this way is sticky: the panel does not silently
  drag focus back to the queue's head while the user is deliberately
  checking in on it.

## Validation

- `scripts/dev/preflight.sh` passed on the pinned toolchain.
- `scripts/dev/run-tests.sh` ran the full suite; the pre-existing,
  load-sensitive subprocess wall-clock timing flakes intermittently missed
  their bound only under heavy background load (a different subset each
  run: `executableVersionProbeKillsACommandThatWouldOtherwiseHang`,
  `GrokSubprocessTransportShutdownTests.shutdownWaitsUntilTheChildProcessHasExited`,
  `GitProcessRunnerDeadlineTests.oversizedOutputIsTruncatedThroughTheGitRunner`,
  `captureScreenshotTimesOutOnAHangingProcess`) and passed individually in
  isolation on every run; `git diff` against every file behind those tests
  is empty.
- `ActivityStackEngineTests` (unchanged, pure ordering/suppression logic)
  and `SidebarReorderTests` (constructs a real `ActivityStackModel`) still
  pass.
- The arm64 Release build succeeded; `scripts/release/verify-app.sh` and
  `scripts/release/security-scan.sh` passed.
