# Conan Code 0.6.12

Fixes the original embedded-terminal overflow: Ghostty's Metal layer painted
past the pane into the tab strip, the prompt input, and the sidebar. The
corruption was still happening on 0.6.11; this release sizes the terminal
from the NSView that actually hosts it.

## Root cause

0.6.7 stopped sizing Ghostty from `NSView.bounds` and instead fed it
SwiftUI's `GeometryReader` size on every `updateNSView`. Instrumenting a
live, already-broken window showed those two numbers routinely disagree:
`hostSize` (GeometryReader) was larger than the hosting NSView's `bounds`
by about 50pt vertically and, when the sidebar/Activity Stack was in play,
by the sidebar width horizontally.

Ghostty was therefore told to render a grid bigger than the view that
clipped it — and because SwiftUI does not clip an `NSViewRepresentable`,
and Ghostty's Metal/IOSurface layer often replaces the view's own layer
(dropping `masksToBounds`), that extra content painted straight into
neighboring chrome. A discrete resize forced a full relayout that made
the two sizes agree again, which is why it looked intermittent.

0.6.7's GeometryReader change, 0.6.8's clipping container, and 0.6.11's
Activity Stack identity fix were all real, but none of them stopped Ghostty
from being given a size its NSView did not have.

## Fix

- `TerminalSurfaceRepresentable` is again an `NSViewRepresentable` that
  fills SwiftUI's proposal via `sizeThatFits`, so the clipping container
  is the pane's actual slot.
- Ghostty is sized from that container's `bounds` converted to backing
  pixels with the window's own `backingScaleFactor`, never from an
  independent GeometryReader size.
- The clipping container pins its hosted view to `bounds` on every
  `layout()` and re-applies `masksToBounds` / `clipsToBounds`, because
  Ghostty may replace the inner view's layer and drop the mask.
- Hidden surfaces hide both the container and its layer, so an
  opacity-0 ZStack sibling cannot keep compositing a Metal drawable.

## Validation

- Reproduced live on 0.6.11 on the user's ultrawide (1x) display, with
  the terminal painting through the Activity Stack list and over the
  prompt input, without quitting the app.
- Instrumented `layout` / `sizeDidChange` confirmed GeometryReader size
  ≠ NSView bounds at the moment of the corruption.
- `scripts/dev/preflight.sh`, focused terminal suites, and the full
  `scripts/dev/run-tests.sh` suite.
- Arm64 Release `scripts/release/verify-app.sh` and the security gate.
