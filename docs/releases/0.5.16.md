# Conan Code 0.5.16

Fixes registering a remote computer, which failed on its first step.

## Highlights

- Conan Code's SSH control socket lives under `Application Support`, and
  OpenSSH's option lexer splits `-o` values on whitespace, so the space in that
  path produced `keyword controlpath extra arguments at end of line` and no
  remote computer could ever be added. The value is now quoted.

## Verification

- A regression test runs the real `ssh` binary with the real default control
  path, and the SSH tests and the remote-host UI test now use directories whose
  names contain a space, which is the shape the product actually uses.
- The remote-host interface passed end to end against a real second Mac:
  registering, `Connected`, adding a remote project through the picker, the host
  badge, and removal.
