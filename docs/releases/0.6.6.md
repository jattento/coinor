# Conan Code 0.6.6

Removes every piece of the Telegram remote-work surface from the application.

## Telegram removal

The Telegram pairing feature shipped behind ADR-0015 is gone entirely:

- `Coinor/Telegram/` (Bot API client, bridge, router, token stores, topic
  catalog, turn builder, speech transcription) and the Telegram settings view
  are deleted, along with `AppCoordinator+Telegram.swift` and all six
  Telegram test files.
- `AppCoordinator` no longer owns a `TelegramBridge`; startup, shutdown,
  archive/unarchive, title sync, catalog rebuilds, and subagent lifecycle
  forwarding no longer touch any Telegram state.
- `MetadataDocument` drops the `telegram` field; existing `metadata.json`
  documents simply ignore the now-unused key on load.
- The sidebar context menu loses "Share on Telegram", Settings loses the
  "Coinor Telegram" file tab, and `Info.plist` drops the microphone and
  speech-recognition usage descriptions that existed only for Telegram voice
  notes.
- ADR-0015, the Telegram remote-work proposal, and the Telegram sections of
  the product requirements, architecture, glossary, and README are removed.

## Validation

- `CoinorTests.GrokControlClientTests`: the ACP-wire test now builds prompt
  blocks directly instead of going through the deleted turn builder.
- `CoinorTests.AppFoundationTests`: the bundle-identity test no longer
  requires the removed microphone usage description.
- `CoinorTests.RemoteShellExecutionTests`: the stop-command decoy is compiled
  from a one-line C source instead of copying `/bin/sleep`, which macOS 26
  kills on spawn; the assertion is unchanged.
- `CoinorTests.SettingsFileCatalogTests`: every remaining tab still edits its
  own file with `fresh`.
- Full Coinor test suite via `scripts/dev/run-tests.sh` on the pinned
  toolchain (Xcode 26.6, macOS SDK 26.5, Swift 6.3.3).
- `scripts/release/verify-app.sh` on the arm64 Release bundle.
- Security gate (`gitleaks` plus targeted credential/path checks) over the
  repository history, working tree, and the application bundle.

## Artifact

`Coinor-0.6.6-arm64.zip` is an ad-hoc signed, non-notarized personal build for
Apple Silicon running macOS 13 or newer.
