# Conan Code 0.5.24

Lets an ordinary click reach the application that captured the mouse.

## Highlights

- Clicking a control drawn by a full-screen terminal application, such as
  Grok's `[Copy Source]` affordance under a rendered diagram, usually did
  nothing until the click was repeated. The click reached the terminal but
  never reached the application.
- While an application captures the mouse, Conan Code defers the press until
  the button is released so it can still tell a click from a drag, and it
  routes a drag with Shift forced on so dragging selects text without holding
  Shift. Promotion to a drag fired on the very first pointer movement, so the
  hand jitter of an ordinary click turned that click into a selection. A
  selection carries Shift, the embedded terminal never lets an application
  capture Shift, and the whole gesture was therefore consumed locally: neither
  the press nor the release was ever reported.
- A deferred gesture now becomes a drag only after the pointer travels more
  than five points from the press. Click jitter stays a click and is reported
  as a complete press and release, while a deliberate drag still promotes
  before it reaches a neighbouring cell, so dragging to select text is
  unchanged.
