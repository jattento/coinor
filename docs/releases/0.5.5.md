# Conan Code 0.5.5

The embedded Ghostty terminal theme now matches the Codex desktop app's own
"Codex Dark" theme card, and the base terminal letter color is warm instead
of stark white.

## Highlights

- `GhosttyOverrides.conf` surface black (`palette 0`) moves from `#2d2d2d` to
  `#2d2d2b` to match the Codex Dark card's `surface` swatch exactly.
- A single bright blue `#339cff` accent (the card's `accent` swatch) now
  drives the terminal cursor (`cursor-color`) and, through a newly explicit
  `AccentColor` asset color, the selected-tab underline in
  `TerminalTabStrip` -- the only other consumer of `Color.accentColor` in the
  app, so no other UI changed.
- `foreground` and `selection-foreground` move from `#e8e8e8` to a warm
  `#faf3dd` cream, by explicit request, rather than the card's literal
  `#ffffff`. Contrast against the unchanged `#181818` background improves
  slightly (16.0:1 vs the previous 14.5:1).
- The ANSI palette (diff/status colors: soft green, coral red, amber
  warning, sky blue, purple, cyan) is unchanged.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Application Support
  paths.
- Existing metadata remains compatible.
- The bundled Ghostty dependency remains pinned to v1.3.1.
