# Conan Code 0.5.15

## Highlights

- The sidebar's `Remote Computers` menu gains `Hide Remote Projects` and
  `Show Remote Projects`. Hiding is presentation only: registered computers
  stay registered, their runtimes keep running, nothing is archived, and the
  choice survives relaunch.
- The remote computers view no longer sends the user back to the menu they
  just used: its empty state explains that Conan Code offers the hosts in the
  SSH configuration and stores no credentials, and adds the computer directly.

## Compatibility

- Metadata schema version 5 stores whether remote projects are hidden. Older
  documents migrate with it disabled.
