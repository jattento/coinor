# Conan Code 0.5.21

Brings an unreachable remote computer back on its own.

## Highlights

- A registered computer that was asleep, restarted, or off the network stayed
  unreachable until it was removed and added again: the periodic refresh only
  iterated hosts that were already connected. It now retries every registered
  host that has no runtime or is marked unreachable.
- The remote computers view gained a `Reconnect` action and now shows why a
  computer is unavailable instead of a generic line.
