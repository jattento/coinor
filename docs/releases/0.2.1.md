# Coinor 0.2.1

Coinor 0.2.1 makes sidebar reordering feel like a native direct-manipulation
interaction instead of a drop-after-the-fact command.

## Highlights

- Projects now lift into a translucent preview that follows the pointer while
  the sidebar opens an animated destination space before release.
- Conversations can now be reordered inside their project, and pinned
  conversations can be reordered inside `Pinned`.
- Drag scopes are isolated: conversations cannot cross projects or move
  between a project and `Pinned`.
- Holding a drag near a sidebar edge uses native list auto-scroll.
- Releasing outside a valid destination cancels the drag and restores the
  original order without writing metadata.
- Archived projects and hidden pinned or archived conversations retain their
  canonical slots and return to the user-defined position when restored.

## Compatibility

- Metadata remains on schema 2, so Coinor 0.2.0 remains usable as a rollback.
- Conversation order is an optional project metadata field. Coinor 0.2.0 can
  read the file but may discard conversation ordering after it writes metadata.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- Debug and Release Apple Silicon builds passed.
- 31 XCTest, 145 Swift Testing tests, and 3 XCUITest passed.
- Real project and conversation drags verified pointer-following previews,
  animated insertion spaces, relaunch persistence, edge auto-scroll, and
  cancellation without metadata changes.
- The release bundle, source delta, archive, and release notes were scanned for
  secrets and private local paths.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
