# Conan Code 0.6.14

Stops `NavigationSplitView` from overlaying the sidebar on top of a
full-width detail column. That presentation — not the terminal — is what
every "the terminal is misaligned" report has been showing.

## Root cause

`AppShellView` used `NavigationSplitView` with no explicit column
visibility and no explicit style, so the style resolved as `.automatic`.
On macOS, `.automatic` is free to present the split as *prominent detail*:
the detail column is laid out across the whole window from x=0 and the
sidebar floats on top of it.

That is exactly the reported rendering:

- The `+` new-tab button was visible while the `main`/`IDE` tabs beside it
  were not — those tabs are plain SwiftUI views, hidden behind the sidebar.
- Terminal text was clipped on the left (behind the sidebar) and ran past
  the right window edge.
- The conversation content ghosted faintly *through* the sidebar, because
  the sidebar is a translucent material with the detail pane sitting
  underneath it.
- Any window resize made it snap back, because the resize re-resolved the
  presentation.

Earlier releases treated the symptom one layer at a time — Ghostty's grid
size (0.6.7, 0.6.12), layer clipping (0.6.8), and view identity of the
detail (0.6.11) and sidebar (0.6.13) columns. None of them could help,
because the pane itself was being placed under the sidebar by the split
view.

## Fix

- `columnVisibility` is now bound to app state pinned at `.all`.
- `.navigationSplitViewStyle(.balanced)` keeps the sidebar beside the
  detail at every window size instead of allowing the overlay
  presentation.

## Validation

- Reproduced on installed 0.6.13, with the detail pane under a translucent
  sidebar and overflowing the right window edge.
- After the fix: six rounds of Activity Stack toggles interleaved with
  sidebar hide/show toggles, then a resize down to the 840pt minimum
  window width (the classic trigger for the overlay presentation) and back
  up. The sidebar stayed beside the detail, the tab strip stayed visible,
  and no content rendered under the sidebar or past the window edge.
- `scripts/dev/run-tests.sh`: 563 tests in 45 suites. Only the documented
  load-sensitive `oversizedOutputIsTruncatedThroughTheGitRunner` timing
  flake failed under full-suite load; it passes in isolation and its files
  are untouched by this change.
- Arm64 Release build, `scripts/release/verify-app.sh`, `git diff --check`,
  and the security gate.

for Apple Silicon running macOS 13 or newer.
