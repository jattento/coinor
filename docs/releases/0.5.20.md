# Conan Code 0.5.20

## Highlights

- The environment every embedded terminal starts with is now built outside the
  AppKit surface, so its guarantees are asserted directly: every local and
  remote terminal carries `COLORTERM=truecolor` and never carries `NO_COLOR`.

## Compatibility

- No behavior change from 0.5.19; this makes that fix impossible to regress
  silently.
