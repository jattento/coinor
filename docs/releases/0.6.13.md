# Conan Code 0.6.13

Fixes the terminal-misalignment bug for real: the detail column, not the
terminal, was in the wrong place. 0.6.7 through 0.6.12 all treated symptoms
downstream of it.

## Root cause

`AppShellView` swapped which view occupied `NavigationSplitView`'s sidebar
column:

```swift
Group {
    if activityStack.isPresented { ActivityStackSidebarView(...) }
    else { AppShellSidebar(...) }
}
.navigationSplitViewColumnWidth(min: 230, ideal: 278, max: 400)
```

Changing the view identity of a split column makes NavigationSplitView
recompute its geometry, and it can land in a state where the **detail**
column is laid out at the full window width starting at x=0 — sliding
underneath the sidebar, which then draws on top of it.

The screenshot that proved it: the `+` new-tab button was visible, but the
`main` and `IDE` tabs next to it were not. Those tabs are plain SwiftUI
views, not terminal content. They were hidden behind the sidebar because
the whole detail pane was shifted left, with its right side overflowing
past the window edge. Terminal text was clipped on the left for exactly
the same reason.

This is the same failure mode 0.6.11 fixed on the detail side (a second
`RuntimeHostView` swapped in by identity); it was still present on the
sidebar side.

## Fix

`AppShellSidebarHost` now occupies the sidebar column permanently. Both the
conversation list and the Activity Stack queue stay mounted inside it, and
only opacity, hit testing, and accessibility visibility change. The column's
identity — and therefore the split's geometry — never changes when the
Activity Stack opens or closes.

## Validation

- Reproduced on installed 0.6.12 with the detail pane rendering under the
  sidebar and past the right window edge.
- After the fix: 10 rapid Activity Stack toggles interleaved with window
  resizes left the tab strip, terminal, and sidebar correctly positioned,
  in both panel states.
- `scripts/dev/run-tests.sh`: 563 tests in 45 suites, all passing.
- Arm64 Release build, `scripts/release/verify-app.sh`, `git diff --check`,
  and the security gate.
