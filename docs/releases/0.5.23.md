# Conan Code 0.5.23

Sends a find request to whoever actually holds the text.

## Highlights

- `Cmd+F` in a Grok pane searched only the rows on screen. A Grok pane runs
  Grok's full-screen interface on the terminal's alternate screen, and an
  alternate screen has no scrollback at all, so a terminal-level search there
  can never see more than the visible rows. The conversation belongs to Grok,
  so `Cmd+F` now writes `/find ` into the pane and Grok searches the whole
  conversation. The text arrives without a newline, so nothing is ever sent by
  accident.
- Shell tabs, managed tabs, and the IDE panes keep the terminal find bar
  introduced in 0.5.22: they own real scrollback, and libghostty searches all
  of it.
- The terminal context menu now offers `Find in Conversation…` in a Grok pane
  and `Find…` / `Find Next` / `Find Previous` everywhere else.
