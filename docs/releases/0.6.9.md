# Conan Code 0.6.9

Adds the Activity Stack: a toolbar-opened attention queue that lets you
answer waiting agents one after another without manually switching
conversations in the sidebar.

## Activity Stack

A new toolbar button (badge shows the current queue count) or `⌘⇧A` opens the
Activity Stack from anywhere, including while a terminal has keyboard focus.
While open, it replaces the sidebar's own Pinned/Projects list with the queue
— the same way the sidebar's Agent Search panel already takes over that
column — and the content area shows the focused conversation's real terminal
directly, tab strip included, exactly as the normal conversation view would.

The queue holds every non-dormant, non-archived, non-closed conversation
Grok reports as needing input, failed, or finished, even ones never opened
this run. It orders by how much each one blocks you: needs input first, then
failed, then finished; within a group, the longest-waiting conversation
leads.

Answering a conversation in its own terminal (text, image, or audio — the
same input already in use) advances the queue on its own once it goes back
to working. If nothing else is waiting, the panel keeps showing that same
conversation instead of jumping to an empty state, so a run of clarifying
questions never bounces the screen back and forth. When the queue is
genuinely empty, a waiting screen with the Conan mascot appears and updates
itself the moment an agent needs you.

Per-item actions: `⌘D` acknowledges and removes it until it raises a new
instance of attention; `⌘S` sends it to the end of the current pass; a
snooze menu removes it for 15 minutes or 1 hour and returns it automatically;
`⌘M` mutes it until restored by hand or until a fresh instance of attention
(a new failure always resurfaces a muted conversation once). Muted and
snoozed conversations keep running and appear in the sidebar's "Out of the
queue" section; the sidebar also lists every actively working agent by name.
Queue state is session-only and does not survive a relaunch.

## Validation

- `scripts/dev/preflight.sh` passed on the pinned toolchain.
- `scripts/dev/run-tests.sh` ran the full suite; the pre-existing,
  load-sensitive subprocess wall-clock timing flakes
  (`executableVersionProbeKillsACommandThatWouldOtherwiseHang`,
  `GrokSubprocessTransportShutdownTests.shutdownWaitsUntilTheChildProcessHasExited`)
  intermittently missed their 2-second bound only under heavy background
  load and passed individually in isolation; `git diff` against every file
  behind those tests is empty.
- New `ActivityStackEngineTests` cover queue ordering, the needs-input/
  failed/finished reason derivation, dismiss/mute/snooze/push-to-end
  suppression and its fingerprint-based expiry, and that `.completed`
  ("session closed") never enters the queue.
- The arm64 Release build succeeded; `scripts/release/verify-app.sh` and
  `scripts/release/security-scan.sh` passed.
