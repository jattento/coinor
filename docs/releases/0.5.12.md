Conan Code 0.5.12

Project rows in the sidebar are now flat `List` rows instead of a
`DisclosureGroup`. A long-lived sidebar could leave a collapsed project header
sitting at the indentation of the conversations it owns, so the row drifted
right by one indent level and its title truncated early while every other
project stayed on the shared leading edge.

The sidebar now owns that geometry: the header draws its own disclosure
chevron, and conversation rows carry an explicit leading indent. `List` no
longer has outline indentation to keep, so the misalignment cannot reappear
during a session. Header alignment, chevron placement, click-to-toggle,
project reordering, and conversation rows keep their previous positions and
behavior.
