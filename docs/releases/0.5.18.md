# Conan Code 0.5.18

Fixes opening a conversation in a remote project.

## Highlights

- A remote conversation showed `The terminal working directory is unavailable`
  instead of a terminal, because the surface checked the conversation's
  directory against this computer's file system while that directory exists
  only on the remote computer. The check now skips remote launches and still
  reports a directory that has not resolved yet.

## Verification

- The remote-host UI test now starts a conversation in the remote project it
  adds and fails if the unavailable-directory message appears. It passed end
  to end against a real second Mac.
