# Conan Code 0.6.4

An upstream-sync health signal for the Grok fork, and Conan Code's first
original app icon.

## Upstream sync warning

Conan Code already warned when a newer `jattento/grok-build` release was
available. It had no signal for a different failure mode: the fork's `main`
silently drifting behind the original `xai-org/grok-build` repository between
syncs, with no release cut yet to surface it.

- `GitHubGrokUpstreamSyncChecker` asks GitHub's compare API how many commits
  `xai-org/grok-build`'s `main` has that the fork's `main` is missing, on the
  same six-hour cadence as the existing update check.
- When the fork is behind, the toolbar shows a small, non-blocking warning
  distinct from the existing release-update indicator; it links straight to
  the GitHub compare view. When the fork is caught up, nothing is shown.
- The `jattento/grok-build` fork itself was resynced with upstream as part of
  this change: fetched, rebased, one real merge conflict resolved (a
  `markdown_content.rs` helper upstream had moved into
  `xai_grok_pager_render::appearance`, and a new `is_family_switch` field on
  a provider-fallback retry path upstream added concurrently), verified, and
  pushed. `ahead_by` against `xai-org/grok-build` is `0`.

## App icon

Conan Code shipped without a custom icon until now. It has an original,
illustrated icon inspired by Jose's dog Conan — not a photo, and not a crop or
filter of one — capturing his tongue-out grin and blue harness as a flat,
vector-style character on a dark teal gradient.

## Validation

- `CoinorTests.GrokUpstreamSyncCheckerTests`: the missing-commits decision
  logic against real "behind" and "caught up" compare payloads, plus an
  `AppShellModel` test driving the real checker end to end.
- `CoinorTests.AppFoundationTests`: the new toolbar accessibility identifier
  is pinned alongside the existing ones.
- Full Coinor test suite via `scripts/dev/run-tests.sh`; Debug build, Release
  build, and `scripts/release/verify-app.sh` on the pinned toolchain (Xcode
  26.6, macOS SDK 26.5, Swift 6.3.3).
- `AppIcon.appiconset` present in `Assets.xcassets`, wired through
  `ASSETCATALOG_COMPILER_APPICON_NAME`, and confirmed as `AppIcon.icns` in the
  built bundle's `Contents/Resources`.
- Grok fork: `cargo check -p overlay-core && cargo test -p overlay-core` (29
  tests), `cargo build -p xai-grok-pager-bin`, and
  `overlay/scripts/overlay-diff.sh` (touchpoint and delta-budget gates) all
  pass after the rebase.
- Security gate (`gitleaks` plus targeted credential/path checks) over both
  repositories' history, working tree, and the application bundle.

## Artifact

`Coinor-0.6.4-arm64.zip` is an ad-hoc signed, non-notarized personal build for
Apple Silicon running macOS 13 or newer.
