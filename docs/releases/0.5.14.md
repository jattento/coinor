# Conan Code 0.5.14

Corrections found by exercising remote hosts against a real second Mac.

## Highlights

- Stopping a remote runtime now waits for the leader to exit and escalates to
  `SIGKILL`, mirroring the local shutdown. It previously sent one `SIGTERM` and
  returned while the runtime was still running.
- The remote compatibility probes send the remote computer's home directory as
  their working directory instead of this computer's.
- `Info.plist` declares `NSLocalNetworkUsageDescription`, and a denied
  local-network connection now says so instead of surfacing OpenSSH's
  undefined-error text.
- `~/.ssh/config` host lines with trailing comments no longer offer the comment
  words as additional host aliases.

## Verification

- The full test suite passed with 0 failures, including new suites that execute
  every composed remote command in a real shell and run the real `ssh` binary.
- Live against a second Mac: probe, remote Git project resolution, remote
  discovery, twelve multiplexed channels, a remote login shell, `fresh` and
  `lazygit`, a remote Grok conversation, `--resume` of an existing remote
  conversation reported as resident, and a remote runtime stop that left that
  computer's own Conan Code leader untouched.
