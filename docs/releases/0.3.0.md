# Coinor 0.3.0

Coinor 0.3.0 adds persistent, Coinor-owned terminal tabs to every
conversation.

## Highlights

- Every conversation starts with a permanent `main` tab containing its Grok
  root and subagent panes.
- The `+` button and `Command-T` create independent Ghostty shells in the
  conversation's exact checkout or worktree.
- Shell tabs stay alive while hidden, including across tab and conversation
  switches and while their conversation is archived.
- Double-clicking any tab enables inline rename with Return, blur, and Escape
  behavior.
- Shell tabs close through their close button, `exit`, `Command-W`, or
  Ghostty's close-tab action, then select the tab to their left.
- Tabs can be reordered while `main` remains fixed first.
- Names, order, selected tab, and monotonic numbering persist across relaunch;
  shell processes are recreated in the original checkout.
- `Command-1` through `Command-9` and Ghostty tab navigation, move, and rename
  actions route into Coinor's tab model.
- The tab strip follows the active Ghostty theme and scrolls horizontally for
  large tab sets.
- Missing conversation directories render an inline error instead of
  launching a shell in the wrong location.

## Compatibility

- Coinor metadata advances to schema 3 to persist conversation tab state.
- Coinor 0.3.0 migrates schema 2 metadata automatically.
- Coinor 0.2.1 intentionally rejects schema 3 rather than rewriting it. To
  roll back after 0.3.0 has saved metadata, restore the pre-upgrade
  `metadata.json` backup before launching 0.2.1.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- Debug and Release Apple Silicon builds passed.
- 185 unit tests and 3 XCUITest passed with no failures or skips.
- Real-app QA covered independent shells, exact working directories,
  background execution, close and rename behavior, Ghostty action routing,
  persistence, 20-tab overflow, archive continuity, and missing-directory
  errors.
- The release bundle, repository boundaries, Ghostty artifact, source delta,
  archive, and release notes passed their verification and security gates.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
