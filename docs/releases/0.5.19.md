# Conan Code 0.5.19

Restores Grok's full theme catalog in Conan Code's terminals.

## Highlights

- Grok treats `NO_COLOR` as set even when empty, so a value inherited from
  whatever launched the application silently stripped color from every
  embedded terminal and left Grok offering only its two non-truecolor themes.
  Conan Code now removes it from its own environment at start-up; a shell
  running inside a terminal can still set it.
- Local surfaces set `COLORTERM=truecolor` explicitly, and remote Grok, shell,
  and IDE commands carry it too: SSH forwards `TERM` but never `COLORTERM`, so
  a remote pane's Grok saw a downgraded terminal.
