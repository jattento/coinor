# Conan Code 0.5.2

Conan Code now supports global keyboard navigation between conversations in
the sidebar.

## Highlights

- Added `Command-Option-Up Arrow` and `Command-Option-Down Arrow` to select
  the previous or next conversation in the sidebar's current visible order.
- Covered pinned conversations, conversations inside expanded projects, and
  active search results; collapsed project contents are skipped.
- Kept the shortcut working while a terminal pane has focus, and suspended it
  while a sidebar drag reorder is active.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Application Support
  paths.
- Existing metadata remains compatible.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- New `SidebarConversationNavigation` and `ConversationNavigationShortcut`
  unit tests cover adjacent movement, list boundaries, a hidden selection,
  an empty visible list, and the window-local shortcut monitor including
  event repeats.
- 179 unit and integration tests and 3 XCUITests passed with no failures or
  skips.
- `scripts/phase0/check-boundaries.sh` passed with the canonical sibling
  `grok-build` checkout supplied through `GROK_BUILD_ROOT`.
- `scripts/ghostty/verify.sh` passed for Ghostty tag `v1.3.1`, commit
  `332b2aefc6e72d363aa93ab6ecfc86eeeeb5ed28`.
- `scripts/release/verify-app.sh` passed for the exact Release bundle and the
  archive-extracted application.
- `scripts/release/security-scan.sh` found no secrets or private local paths
  in Git history or the publishable source snapshot.
- `git diff --check` and shell syntax checks passed.
- The archive checksum verified, and `diff -qr` found no difference between
  the built and archive-extracted application bundles.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
