# Conan Code 0.5.26

Makes conversation organization predictable, remote disconnects quiet, and search capable of finding the conversation you meant.

## Highlights

- Conversations discovered for the first time now appear newest-first without disturbing established drag ordering. Newly pinned conversations move to the top of Pinned, while existing user ordering remains stable.
- Archiving is immediate and no longer asks for confirmation. Archived conversations are unpinned and their main, IDE, shell, and managed terminal runtimes are stopped at once. Archiving a project applies the same rule to every conversation it contains.
- The existing fuzzy-search field now includes an Agent Search mode. Its compact native mini-chat uses an ephemeral Grok session to search active and archived conversations by title plus transcript-derived context, including conversations on connected remote hosts.
- Agent Search lists matches without mutation. It opens, unarchives, or pins only when the request explicitly asks for that action; opening a result row never pins it implicitly. Closing the search or relaunching Conan Code clears the ephemeral transcript and state.

## Remote hosts

- A disconnected remote host keeps its unavailable badge and reconnect action without leaving an intrusive warning in the main interface.
- Each connected-to-unavailable episode sends one native macOS notification. Repeated retries are silent, and a successful reconnection rearms the next episode.

## Reliability and safety

- Agent Search disables subagents and web search, uses a restricted permission mode, denies filesystem, shell, scheduler, integration, and mutation tools, and deletes its ephemeral Grok session after use.
- Local export processes are cancellable with bounded termination escalation, stale Agent Search sessions are retried for cleanup on launch, and local and remote transcript extraction is bounded before it is sent to the finder.
