# Conan Code 0.5.30

This release closes the Conan Code findings from the 16 August 2026 quality
audit: framing and metadata crashes, Agent Search containment, Ghostty
clipboard lifetime, remote-host lifecycle leaks, subprocess bounds, and the
unversioned Grok couplings.

Finding 39 (splitting the three large coordinators) is deferred; the concrete
bugs it caused already have owners inside those files.

## Security and crashes

- ACP framing rejects oversized lines before extraction and rejects a negative
  or overflowing `Content-Length` instead of trapping.
- Agent Search now passes Grok's `--tools` allowlist, copies bounded transcript
  excerpts into a 0700 workspace, and never points the agent at the real
  filesystem.
- Ghostty clipboard callbacks and surface teardown share one lock-protected
  handle owner, so a callback cannot complete against a freed surface.
- SSH host aliases that start with `-` are rejected, and every ssh vector
  inserts `--` before the destination.

## Lifecycle and resources

- Remote hosts have an explicit connection state. An explicitly stopped host
  is not auto-reconnected; a failed registration leaves no residue; restart
  and shutdown cancel remote event tasks and close remote clients; catalog
  merges no longer duplicate remote rows.
- Worktree creation and other in-flight coordinator tasks are cancelled on
  teardown and refuse to mutate after a lifecycle generation change.
- Registered hosts connect in bounded parallel batches. The last local
  conversation is restored before remote probes. SSH config aliases are
  cached instead of being re-read during view rendering.
- A negative metadata `schemaVersion` is rejected as corrupt instead of
  hanging startup in a 2^63-step migration loop.
- Local git and remote commands have cancellation-aware deadlines, bounded
  head/tail output, and process-group termination. Grok transport shutdown
  waits for the child to actually exit.

## Correctness

- A malformed subagent lifecycle replay (`updates` / `hasMore` missing or
  wrong-typed) is a compatibility error, not a silent empty page.
- Workflow definitions are selected by origin + path (or origin + name).
  Launching still sends the plain wire name to Grok.
- Agent Search lives in its own child view that observes the finder model, so
  results re-render.

## Cleanup

- Terminal-control method names, JSON keys, and environment variables are a
  shared source file compiled into both Coinor and coinorctl.
- The unused `ConversationPaneCollection` type is gone.
- Phase 0 `Spikes/` trees are removed from the working tree (recoverable from
  git history). Ghostty's build cache no longer lives under `Spikes/`.
- Integration tests pin `grok --help`, `grok --version` (including
  `-overlay.N`), and the on-disk session/skill path conventions against the
  installed `~/bin/grok`.

## Requires

- `~/bin/grok` from `jattento/grok-build` `v1.0.3-overlay.2` or newer.
- macOS 13 or newer on Apple Silicon.

## Validation

- `scripts/dev/preflight.sh` passed with Xcode 26.6 (17F113), macOS SDK 26.5,
  Swift 6.3.3, Developer Tools security enabled, `system.privilege.taskport`
  allowed, and automation mode requiring no authentication.
- `scripts/dev/run-tests.sh` unit tests passed: 452 Swift Testing / XCTest
  cases in 43 suites. The five application-shell UI tests could not activate
  the debug bundle in this session (`Running Background`); they were not
  used as the acceptance gate for these changes. The opt-in live remote-host
  UI test was skipped because `COINOR_LIVE_REMOTE_HOST` was not set.
