# Coinor 0.2.0

Coinor 0.2.0 makes the workspace faster to navigate and restores the complete
interactive Grok terminal experience.

## Highlights

- Added fuzzy conversation search above `Pinned`, ranked by textual closeness
  and then recent activity.
- Added drag-and-drop project ordering with stable positions for archived
  projects and flat, consistent project-header alignment.
- Expanded project appearance to 30 symbols and eight adaptive colors.
- Hid each project's new-conversation control until hover, keyboard focus, or
  accessibility focus.
- Added an advisory toolbar warning when a newer public Grok fork release is
  available.
- Fixed Retina mouse coordinates so Grok hover, click, double-click, and
  expandable task output target the correct row.
- Restored native drag selection and standard clipboard actions while
  preserving Grok's mouse interactions.
- Added the macOS microphone purpose declaration required by Grok Voice.

## Compatibility

- Metadata remains on schema 2, so Coinor 0.1.0 remains usable as a rollback.
- Project order and icon color are optional metadata fields; older builds may
  discard those two presentation preferences after writing metadata.
- The bundled Ghostty dependency remains pinned to v1.3.1.

## Verification

- Debug and Release Apple Silicon builds passed.
- Full unit and UI test suites passed.
- The release bundle, source delta, archive, and release notes were scanned
  for secrets and private local paths.

The application is ad-hoc signed and not notarized. It is intended for the
owner's Apple Silicon Macs rather than Mac App Store distribution.
