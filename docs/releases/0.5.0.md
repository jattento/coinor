# Conan Code 0.5.0

Conan Code now gives Grok agents visible, reusable terminal tabs for
long-running and interactive commands.

## Highlights

- Added a private terminal-control service and bundled native `coinorctl`
  client.
- Added a Grok skill that uses managed tabs for servers, watchers, streaming
  logs, and REPLs while leaving finite commands on Grok's ordinary terminal
  path.
- Added transient managed tabs that start in the background without changing
  the selected tab.
- Added reusable zsh command execution with incremental log reads, text input,
  named keys, Ctrl-C, status, exact managed-command exit codes, and closure.
- Added opaque per-tab capabilities and ACP nonce authorization for exact root
  or subagent ownership.
- Added clear failure outside Conan Code with no background-task fallback.
- Changed archive behavior: loaded conversations and projects now require
  confirmation and then immediately stop Grok, subagents, IDE tools, ordinary
  shells, managed services, and child processes.
- Added a revision-specific compatibility wrapper for Ghostty v1.3.1's
  text-release ABI.

## Compatibility

- The application bundle remains `Coinor.app`, with bundle identifier
  `dev.coinor.Coinor`, executable `Coinor`, and existing Application Support
  paths.
- Existing metadata stays compatible. Managed terminal tabs, capabilities,
  processes, and scrollback are never persisted.
- The bundled Ghostty dependency remains pinned to v1.3.1.
- Conan Code installs and updates only its own
  `~/.grok/skills/conan-code-long-running` directory.
