# Conan Code 0.5.22

Rebuilds the sidebar and adds find in terminal.

## Highlights

- The sidebar draws its own rows instead of leaning on `List`: a row is now a
  pill inset from the sidebar edges, a project reads heavier than the
  conversations it owns, and a conversation title starts exactly under the
  title of its project.
- A project header carries its identity and its disclosure control in one
  slot: the project icon reads at rest and the chevron takes over on hover, so
  titles start closer to the edge and stay readable.
- Conversation titles keep the full row width until the pointer arrives. The
  pin and archive controls no longer reserve space that nothing is using, and
  the sidebar opens slightly wider.
- `Cmd+F` opens a find bar on any terminal: the Grok pane, subagent panes, the
  IDE panes, and every shell tab. Typing searches the scrollback live, `Return`
  and `Shift+Return` walk the matches, `Cmd+G` and `Cmd+Shift+G` do the same
  from the terminal, and the bar reports the match count. `Escape` or the close
  button ends the search and returns typing to the terminal.
- A selection is used to seed the needle, so selecting a word and pressing
  `Cmd+F` searches for it immediately. `Find…`, `Find Next`, and `Find
  Previous` also appear in the terminal context menu.
